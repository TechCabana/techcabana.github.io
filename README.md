## Overview

This is a single-page portfolio site: an introduction, a work history, a skills matrix, a
set of project deep-dives, education, and a contact form. It is hand-written HTML, CSS and
one plain JavaScript file, served by GitHub Pages. There is no framework, no build step, no
package manager and nothing running on a server.

The work history covers six roles across product management, data governance and delivery,
each with the outcomes rather than the job description. The skills matrix groups six
categories and filters by level, so the page reads quickly whether you want the headline or
the detail. Four projects sit below it, and each one has its own deep-dive page — what it
does, why it was built that way, and what it looks like — which opens in place rather than
sending you somewhere else. Education and a contact form close the page.
